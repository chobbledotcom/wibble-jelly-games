{%- comment -%} Search box component. Submits to /search/ with the query as a ?q= parameter. The field and its button are both named from the page language's `search_label`, because the button's only content is an icon. Optional parameters: - placeholder: Custom placeholder text (default: the language's search label) - button_icon: Button content - supports Iconify IDs, image paths, emojis, or text (default: "hugeicons:search-02") {%- endcomment -%} {%- assign placeholder = placeholder | default: pageLanguage.search_label -%} {%- assign button_icon = button_icon | default: "hugeicons:search-02" -%}
