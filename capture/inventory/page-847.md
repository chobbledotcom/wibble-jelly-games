# Kaboom – Space!

[figure.wp-block-media-text__media]
![](https://wibblejellygames.com/wordpress/wp-content/uploads/KaboomSpace-1-799x1024.png) width=799 height=1024 class=wp-image-849 size-full srcset=https://wibblejellygames.com/wordpress/wp-content/uploads/KaboomSpace-1-799x1024.png 799w, https://wibblejellygames.com/wordpress/wp-content/uploads/KaboomSpace-1-234x300.png 234w, https://wibblejellygames.com/wordpress/wp-content/uploads/KaboomSpace-1-768x985.png 768w, https://wibblejellygames.com/wordpress/wp-content/uploads/KaboomSpace-1.png 1000w
Kaboom – Space! is a fun memory game. Try and remember your way through the asteroid field. If you crash into an asteroid you have to start again – can you remember your way?
Kaboom! and Kaboom – Space have identical game play. The only differences are the graphics and some of the audio instructions and the attract music.
Once the start button has been pressed a random course is set by the game through the asteroid field. As each row of LEDs flash the player has to press one of the 4 buttons to select what they think is a safe move. Get it wrong and the LED turns red and the player has to start on the first row again, get it right and the LED turns green and the game advances to the next row.
This game is great at any fun day, corporate event, wedding, youth club, birthday party or any other event you may be having. Kaboom – Space! is build into a sturdy flight case with a removable lid and is mains powered.
Total duration of the game play is 90 seconds resulting in a new contestant approximately every 2 minute. Total throughput is 30 players per hour. However it also works well as a team game with one player pressing the buttons and the others trying to remember the route.
